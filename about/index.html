About

I'm Jorge. I write to think, build to understand, and share work in progress.

This site is a collection of Thoughts, Projects, Ideas, and Photos — a digital garden, not a feed. Notes grow and change over time.

How this site is made

Plain HTML and CSS, no frameworks, no trackers. Hosted on GitHub Pages. Built to be simple, elegant, and functional — like I'd want everything to be.

The layout mimics Obsidian Publish: a file explorer on the left, the note in the center, and a graph plus outline on the right.

Why a garden

A blog is a feed: posts are dated and immediately start to expire. A garden is a place where notes grow, connect, and stay evergreen.
